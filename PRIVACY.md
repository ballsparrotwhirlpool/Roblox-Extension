# Privacy Policy for Roblox Server Navigator

Last updated: September 10, 2026

Roblox Server Navigator is a browser extension that improves public-server browsing on Roblox game pages. This policy explains what information the extension handles and how it is used.

## Information the extension handles

The extension processes the following information only as needed to provide its user-facing features:

- The current Roblox game-page URL and place ID.
- Public Roblox server information, including server IDs, player counts, server capacity, and pagination data.
- User actions within the extension, such as joining, favoriting, avoiding, copying, or searching for a server.
- Extension preferences, including enabled features, theme, player-range settings, favorite and avoided server IDs, the last selected server ID, and temporary cached server totals.

The extension does not collect names, email addresses, passwords, authentication credentials, payment information, health information, personal communications, or precise location information.

## How information is used

Information is used only to provide the extension's server-navigation features, including player filtering, page navigation, server ID search, favorites, avoided servers, random joining, and rejoining a previously selected server.

Preferences and saved server IDs are stored locally on the user's device using Chrome's local storage. They are not transmitted to the developer.

## Data sharing and external requests

Roblox Server Navigator does not sell user data, transfer user data to advertisers, or use data for advertising, profiling, lending, or purposes unrelated to its server-navigation features.

The extension communicates only with official Roblox HTTPS services at `games.roblox.com` and `apis.roblox.com` to request public game and server information and to perform user-requested server actions. The developer does not operate an external data-collection server and does not receive this information.

## Data retention and deletion

Locally saved preferences and server IDs remain on the user's device until they are changed or cleared by the user, removed through the extension's controls, or deleted when the extension is uninstalled. Temporary cached server totals may be replaced or cleared during normal use.

## Remote code

The extension does not download or execute remote code. All executable code is included in the extension package. Responses from Roblox services are treated only as data.

## Changes to this policy

This policy may be updated if the extension's functionality or data practices change. Updates will be published in this repository with a revised date.
